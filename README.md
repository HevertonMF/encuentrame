# Encuéntrame — psicólogos y pacientes

Aplicación web para ayudar a las personas a encontrar al psicólogo que mejor se adapta a su necesidad.

🔗 **Demo:** https://hevertonmf.github.io/encuentrame/

## Funcionalidades

- **Área de pacientes:** registro e inicio de sesión, búsqueda de profesionales por nombre y especialidad (ansiedad, depresión, terapia de pareja, terapia infantil…) y envío de solicitudes de atención.
- **Área de psicólogos:** perfil con presentación y especialidades, y gestión de las solicitudes recibidas (pendiente / contactado).
- Diseño adaptable a móvil y modo claro/oscuro.

## Tecnologías

HTML · CSS · JavaScript (los datos se guardan en el navegador con `localStorage`).

> Proyecto de estudio del ciclo de Desarrollo de Aplicaciones Multiplataforma (DAM) en CEAC. Los perfiles de psicólogos son ficticios.
